# Mapeador Heurístico & Asistente One UI (`v1.4.0`) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolucionar Camera Rescue desde `v1.3.0` hasta `v1.4.0` ampliando la base de datos heurística de hardware Samsung (S9–S25, Note, Z Fold/Flip, Serie A), implementando el mapeador `ShootingModeMap` por versión de One UI, un asistente interactivo guiado para fijar "Ajustes para conservar" (*Settings to keep*) y Tecla lateral (doble toque), y un motor de recuperación rápida ante bloqueos de cámara.

**Architecture:**
1. **`SamsungModelDatabase` ampliada & `ShootingModeMap`**: Perfiles extendidos (S9–S25, FE, Note 9–20, Z Fold/Flip 1–6, Serie A) con capacidades de video Pro, apertura variable y riesgo de bisagra; `ShootingModeMap` resuelve variantes de lanzamiento ordenadas (`PRO_PHOTO`, `PRO_VIDEO`, `QR_SCANNER`) según modelo y generación de One UI (2.x a 8+).
2. **`OneUiAssistantGuide` & `CameraRecoveryEngine`**: Lógica pura para generar pasos guiados adaptados por One UI con progreso persistible, y detección determinista + escalado progresivo de recuperación ante retornos rápidos o bloqueos HAL (`0 -> 1 -> 2 -> 3`).
3. **`OneUiSystemBridge`, `RescuePreferences` & `AndroidManifest.xml`**: Puente Android para detectar `SEM_PLATFORM_INT`/API, lanzar variantes con fallback, abrir Ajustes de Tecla Lateral / Cámara / Info de App, persistir pasos completados y declarar `<queries>` sin `INTERNET`.
4. **`MainActivity` + Sync Build/CI (`v1.4.0`)**: Despacho trasero vía `ShootingModeMap`, detector de retorno rápido en `onResume`/`onError`, tarjetas de Recuperación Rápida y Asistente One UI, y sincronización de `versionCode = 5` / `versionName = "1.4.0"` en Gradle, scripts y GitHub Actions.

**Tech Stack:** Java 17, Android SDK 34 (`minSdk = 30`, `targetSdk = 34`), APIs estándar del SDK sin dependencias externas, pruebas unitarias puras en Java (`scripts/test-local.ps1`), compilación local `aapt2`/`javac`/`d8`/`zipalign`/`apksigner` (`scripts/build-local.ps1`).

## Global Constraints
- **Platform:** Java 17, Android SDK `compileSdk = 34`, `minSdk = 30`, `targetSdk = 34`. Zero third-party dependencies (standard Android SDK APIs only; pure Java unit tests with no JUnit).
- **Privacy & Security:** 100% offline. NEVER add `android.permission.INTERNET`, external libraries, or confidential business docs/keystores. Keep `RearCaptureService` minimal-privilege configuration and package `com.s23plus.camera` unchanged.
- **Version Sync (`v1.4.0`, `versionCode = 5`):** Must match across `CameraConfig.java`, `CameraConfigTest.java`, `AndroidManifest.xml`, `app/build.gradle.kts`, `scripts/build-local.ps1`, and `.github/workflows/release-apk.yml`.
- **TDD Rule:** For all pure Java logic (Tasks 1 & 2), write failing tests first, run `powershell -ExecutionPolicy Bypass -File .\scripts\test-local.ps1` to confirm RED, implement minimal code, re-run to confirm GREEN.
- **Verification Rule:** ALWAYS run and inspect final outputs of both `powershell -ExecutionPolicy Bypass -File .\scripts\test-local.ps1` and `powershell -ExecutionPolicy Bypass -File .\scripts\build-local.ps1` before closing `v1.4.0`.

## Review Focus
1. **Backwards compatibility of `SamsungModelDatabase.ModelProfile`:** Keep the 9-parameter constructor delegating to the 13-parameter constructor so existing callers/tests compile cleanly; fix Note 9 `rearTeleStandaloneId` from `"1"` to `"52"` to avoid collision with `frontWideId = "1"`.
2. **One UI detection fallback:** `ShootingModeMap.detectOneUiGeneration(sdkInt, semPlatformInt)` must safely fall back to `sdkInt` when `SEM_PLATFORM_INT` is unavailable (`0` or `< 100000`) and clamp cleanly at `ONE_UI_2` and `ONE_UI_8_PLUS`.
3. **Rapid-return lockup boundary & single consumption:** `CameraRecoveryEngine.isSuspectedCrashReturn(launchTs, resumeTs)` must be `false` for `launchTs <= 0` or `resumeTs < launchTs`, `true` for `0 <= delta <= 2500`, `false` for `delta > 2500`. `MainActivity.onResume()` must clear `lastRearLaunchTimestampMs = 0L` immediately to avoid double-triggering.
4. **Recovery escalation & UI lifecycle safety:** `CameraRecoveryEngine.buildRecoveryPlan()` clamps `stage` to `[0, 3]`; `MainActivity` cancels `pendingRecoveryRunnable` on `executeQuickRecovery()` and `onDestroy()`, and checks `!isFinishing() && !isDestroyed()` before delayed `startActivity`.
5. **Models without native Pro Video (`supportsNativeProVideo == false` or `ONE_UI_2`):** `ShootingModeMap.resolve(..., PRO_VIDEO)` must set `nativeSupportedOnHardware = false`, provide a safe fallback to `PRO_PHOTO`, and keep `DynamicUiBuilderTest` passing unchanged.
