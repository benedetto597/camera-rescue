English — Privacy Policy

Summary: Rescue Cam: Sensor Recovery (io.github.benedetto597.rescuecam) is a 100% offline local hardware utility. No data collected. No data shared with third parties. The app includes zero analytics, zero telemetry, zero third-party tracking SDKs, zero INTERNET permission, and zero AccessibilityService.

1. Zero Data Collection & Zero Data Sharing

  • No data collected: We do not collect, transmit, store on external servers, or sell personal data, usage metrics, crash telemetry, device identifiers, photos, videos, or audio.
  • No data shared with third parties: Because the application is 100% offline and does not declare android.permission.INTERNET, no data can leave your device through the app.
  • Zero tracking & zero Accessibility API: There are no analytics libraries, no advertising trackers, and no BIND_ACCESSIBILITY_SERVICE components.

2. Android Permissions Breakdown

Permission Status Strict Local Purpose
android.permission.CAMERA Runtime (Required for viewfinder & test) Runs the local Camera2 viewfinder and performs on-device sensor canary probing to verify functional physical/logical cameras.
android.permission.RECORD_AUDIO Runtime (Optional) Requested only when the user starts MP4 video recording in the integrated Camera2 viewer. If denied, recording cleanly degrades to video-only MP4 without audio.
android.permission.BIND_QUICK_SETTINGS_TILE System Tile Binding Allows the user to optionally add a Quick Settings shortcut tile to launch the app. Does not access user data or run background network tasks.

Explicitly omitted permissions: The manifest does not declare android.permission.INTERNET, android.permission.READ_EXTERNAL_STORAGE, android.permission.WRITE_EXTERNAL_STORAGE, android.permission.MANAGE_EXTERNAL_STORAGE, android.permission.READ_MEDIA_IMAGES, android.permission.READ_MEDIA_VIDEO, or android.permission.BIND_ACCESSIBILITY_SERVICE.

3. Local Device Storage Only

All app state and user-created files remain strictly on your device:

  • Preferences: Local SharedPreferences file named camera_rescue_prefs (stores selected sensor defaults, UI toggles, and diagnostic counters; excluded from cloud backup via android:allowBackup="false").
  • Media Output: Photos and videos captured inside the integrated Camera2 viewer are saved locally via Android MediaStore to Pictures/RescueCam (JPEG) and Movies/RescueCam (MP4).
  • Offline Diagnostic Profiles: Users may optionally export or import diagnostic configuration profiles as local .json files using the Android Storage Access Framework (SAF) file picker.

4. Data Deletion Instructions

  • App preferences & diagnostics: Open Android Settings → Apps → Rescue Cam: Sensor Recovery → Storage → Clear storage, or uninstall the application.
  • Captured media & exported profiles: Delete JPEG/MP4 files from Pictures/RescueCam or Movies/RescueCam via your device Gallery/Files app, and delete any user-saved .json profile files manually.

5. Independent Utility & Trademark Disclaimer

Rescue Cam: Sensor Recovery is an independent utility tool. It is not affiliated with, authorized, endorsed, sponsored by, or connected with Samsung Electronics Co., Ltd. The terms “Samsung”, “Galaxy”, and “One UI” are used solely for descriptive technical hardware-compatibility purposes.

Español — Política de Privacidad

Resumen: Rescue Cam: Sensor Recovery (io.github.benedetto597.rescuecam) es una utilidad de hardware local 100% offline. No recopila datos (No data collected) ni comparte datos con terceros (No data shared with third parties). No contiene analíticas, telemetría, rastreadores publicitarios, permiso INTERNET ni AccessibilityService.

1. Cero Recopilación y Cero Compartición de Datos

  • Sin recopilación de datos: La aplicación no recopila, transmite, almacena en servidores externos ni comercializa datos personales, métricas de uso, registros de fallos, identificadores del dispositivo, fotos, videos ni audio.
  • Sin compartición con terceros: Al operar 100% offline y no declarar android.permission.INTERNET, ningún dato puede salir del dispositivo mediante la aplicación.
  • Cero rastreadores y cero API de Accesibilidad: No integra SDKs de analítica ni publicidad, y no declara BIND_ACCESSIBILITY_SERVICE.

2. Desglose Exacto de Permisos

Permiso Estado Uso Local Estricto
android.permission.CAMERA Tiempo de ejecución (requerido para visor y prueba) Ejecuta el visor local Camera2 y las pruebas canario locales de sensores en el propio dispositivo.
android.permission.RECORD_AUDIO Tiempo de ejecución (opcional) Solo se solicita cuando el usuario inicia grabación de video MP4. Si se deniega, la grabación degrada de forma segura a MP4 solo de video sin audio.
android.permission.BIND_QUICK_SETTINGS_TILE Acceso rápido del sistema Permite añadir un mosaico opcional en Ajustes Rápidos para abrir la app; no recopila datos ni ejecuta conexiones de red.

Permisos explícitamente ausentes: No se declaran android.permission.INTERNET, android.permission.READ_EXTERNAL_STORAGE, android.permission.WRITE_EXTERNAL_STORAGE, android.permission.MANAGE_EXTERNAL_STORAGE, android.permission.READ_MEDIA_IMAGES, android.permission.READ_MEDIA_VIDEO ni android.permission.BIND_ACCESSIBILITY_SERVICE.

3. Almacenamiento Exclusivamente Local en el Dispositivo

  • Preferencias: Archivo local de SharedPreferences llamado camera_rescue_prefs (guarda preferencias de sensores e indicadores de diagnóstico; excluido de copias automáticas mediante android:allowBackup="false").
  • Archivos multimedia: Las capturas realizadas en el visor Camera2 integrado se guardan localmente mediante MediaStore en Pictures/RescueCam (JPEG) y Movies/RescueCam (MP4).
  • Perfiles offline en JSON: El usuario puede exportar o importar manualmente perfiles de configuración .json offline mediante el selector de archivos del sistema (Android Storage Access Framework, SAF).

4. Instrucciones de Eliminación de Datos

  • Preferencias y diagnósticos: Ve a Ajustes → Aplicaciones → Rescue Cam: Sensor Recovery → Almacenamiento → Borrar datos, o desinstala la aplicación.
  • Fotos, videos y perfiles JSON: Elimina los archivos locales en Pictures/RescueCam, Movies/RescueCam o las copias .json exportadas desde tu aplicación de Galería o Archivos.
