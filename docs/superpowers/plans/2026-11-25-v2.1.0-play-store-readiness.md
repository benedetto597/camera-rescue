# Play Store Readiness (`v2.1.0`) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preparar Camera Rescue (`v2.0.0` -> `v2.1.0`, `versionCode = 7`) para cumplimiento técnico integral de Google Play Store con branding libre de marcas registradas (`Rescue Cam: Sensor Recovery` / `io.github.benedetto597.rescuecam`), arquitectura cero-accesibilidad (eliminación completa de `RearCaptureService` y `BIND_ACCESSIBILITY_SERVICE`), `targetSdk = 36` con edge-to-edge y pantallas adaptativas, Política de Privacidad estática / Data Safety 100% offline, y pipeline seguro de release APK + AAB sin exponer secretos en Git.

**Architecture:**
1. **Lógica Pura (`CameraConfig`, `RescueActionSpec`, `DynamicUiBuilder`, `OneUiAssistantGuide`, `PlayStoreCompliancePolicy`)**: Identidad `v2.1.0` (`APP_TITLE`, `APP_SHORT_NAME`, `PLAY_APPLICATION_ID`, `TRADEMARK_DISCLAIMER`, `MEDIA_RELATIVE_PATH = "Pictures/RescueCam"`, `VIDEO_RELATIVE_PATH = "Movies/RescueCam"`), reemplazo de `REAR_QR_HUD` por `REAR_QR_DIRECT`, y motor de auditoría `PlayStoreCompliancePolicy` en Java puro (sin `android.*`).
2. **Capa Android (`AndroidManifest.xml`, `MainActivity`, `RescueShortcutManager`, `MediaStoreSaver`, `CameraRescueTileService`)**: Eliminación definitiva de `RearCaptureService.java` y `accessibility_service_config.xml`, `WindowInsets` edge-to-edge (`systemBars | displayCutout`), orientación adaptativa para pantallas grandes/plegables, y tarjeta + diálogo offline de Privacidad, Data Safety y Aviso Legal.
3. **Build & CI/CD Seguro (`build.gradle.kts`, `app/build.gradle.kts`, `proguard-rules.pro`, `scripts/build-local.ps1`, `scripts/build-aab-local.ps1`, `.github/workflows/release-apk.yml`, `.github/workflows/build-play-aab.yml`)**: `compileSdk = 36`, `targetSdk = 36`, R8/ProGuard en release, carga exclusiva de keystores desde variables de entorno, `keystore.properties` (ignorado) o GitHub Secrets en `$RUNNER_TEMP`, y verificación automática con `apksigner` / `aapt2 dump badging` / `jarsigner`.
4. **Privacidad Estática & Documentación (`docs/privacy-policy.html`, `docs/play-store-readiness.md`, `README.md`, `SECURITY.md`, `docs/ROADMAP.md`, `docs/architecture.md`, `docs/ORCHESTRATOR_HANDOFF.md`)**: Política bilingüe autocontenida para GitHub Pages, guía técnica de Data Safety y Upload Key, actualización integral y publicación del tag `v2.1.0`.

**Tech Stack:** Java 17, Android SDK 36 (`compileSdk = 36`, `minSdk = 30`, `targetSdk = 36`), AGP `8.9.1`, APIs estándar del Android SDK sin dependencias externas, pruebas unitarias en Java puro sin JUnit (`scripts/test-local.ps1` — 11 suites), compilación local `aapt2`/`javac`/`d8`/`zipalign`/`apksigner` (`scripts/build-local.ps1`) y Gradle `bundleRelease`.

## Global Constraints
- **Confidentiality:** NEVER copy, cite, reference, or expose private business documents, commercial plans, third-party billing/ads libraries, keystores, or passwords anywhere in the public repository.
- **Zero-Accessibility & 100% Offline:** NEVER declare `android.permission.INTERNET`, `BIND_ACCESSIBILITY_SERVICE`, `SYSTEM_ALERT_WINDOW`, or broad storage permissions (`READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `MANAGE_EXTERNAL_STORAGE`, `READ_MEDIA_*`). `android:allowBackup="false"`.
- **Trademark-Safe Branding:** Public title `"Rescue Cam: Sensor Recovery"` (`<= 30` chars), short name `"Rescue Cam"`, public `applicationId = "io.github.benedetto597.rescuecam"`, neutral MediaStore paths `"Pictures/RescueCam"` and `"Movies/RescueCam"`, explicit independent disclaimer (`TRADEMARK_DISCLAIMER`), while keeping Java package `com.s23plus.camera` and internal `com.s23plus.camera.action.*` constants intact for `.json` profile compatibility.
- **Pure-Java Test Boundary (`scripts/test-local.ps1`):** `javac` compiles `$PureSources` WITHOUT `android.jar`. Every class in `$PureSources` (11 suites) uses only standard `java.*` packages.
- **Version Sync (`v2.1.0`, `versionCode = 7`, `targetSdk = 36`):** Synchronized across `CameraConfig.java`, `CameraConfigTest.java`, `app/build.gradle.kts`, `scripts/build-local.ps1`, `.github/workflows/release-apk.yml`, and `PlayStoreCompliancePolicyTest.java`.
- **Verification Rule:** ALWAYS execute and inspect real outputs of `powershell -ExecutionPolicy Bypass -File .\scripts\test-local.ps1` and `powershell -ExecutionPolicy Bypass -File .\scripts\build-local.ps1`.

## Review Focus
1. **Zero Accessibility & Zero Internet Residual Audit:** No class, XML, manifest entry, script, or badging output may contain `RearCaptureService`, `BIND_ACCESSIBILITY_SERVICE`, `accessibility_service_config`, or `android.permission.INTERNET`.
2. **Dual Package Name Alignment (`applicationId != namespace`):** `aapt2 link` must use `--rename-manifest-package io.github.benedetto597.rescuecam --custom-package com.s23plus.camera` with fully qualified component names in `AndroidManifest.xml`, and `ProGuard` must keep `MainActivity`, `CameraRescueTileService`, and serialized enum names.
3. **Play Store Title & Application ID Rules (`PlayStoreCompliancePolicy`):** Handles `null`/blank, `> 30` chars, trademark impersonation prefixes (`samsung`, `galaxy`, `android`, `google`, `official`), invalid reverse-DNS IDs, and missing disclaimer clauses without throwing or silently passing.
4. **Backward Compatibility of `.json` Profiles & Edge-to-Edge API 36:** `DiagnosticProfileCodecTest` remains 11/11 PASS with existing `com.s23plus.camera.action.*` allowlist; `MainActivity` applies `WindowInsets.Type.systemBars() | WindowInsets.Type.displayCutout()` cleanly and removes fixed portrait orientation lock.
5. **Release Signing Secret Safety:** `app/build.gradle.kts`, `.gitignore`, and workflows must never commit keystores or fall back to `debug` signing inside `release` `buildType`; CI temp keystores must always be deleted in `if: always()`.
