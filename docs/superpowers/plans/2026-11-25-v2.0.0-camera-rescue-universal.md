# Camera Rescue Universal (`v2.0.0`) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolucionar Camera Rescue desde `v1.4.0` hasta `v2.0.0` (Fase 3 — Camera Rescue Universal) añadiendo un visor Camera2 nativo completo reutilizable para sensores frontales y traseros públicos operativos (zoom digital seguro, compensación EV, flash/linterna, temporizador, cuadrícula y apertura variable mecánica $f/1.5 \leftrightarrow f/2.4$), grabación transaccional de video MP4 en `MediaStore` con degradación limpia sin audio si `RECORD_AUDIO` se deniega, y exportación/importación local offline de perfiles en `.json` vía Storage Access Framework (SAF).

**Architecture:**
1. **`CameraConfig`, `CameraViewerMath`, `VideoRecordingState` & `DynamicUiBuilder`**: Lógica 100% Java pura (sin `android.*` ni `org.json.*`) para cálculos de zoom/crop (`CONTROL_ZOOM_RATIO` en API 30+ vs `SCALER_CROP_REGION`), EV, modos de flash/linterna, apertura variable (`LENS_APERTURE`), orientación por facing, máquina de estados de grabación MP4 (`IDLE`/`PREPARING`/`RECORDING`/`STOPPING`) y selectores públicos de visor universal.
2. **`DiagnosticProfileCodec`**: Codificador/decodificador JSON RFC-8259 recursivo descendente en Java puro con validación estricta de esquema, límites de tamaño/sensores, lista blanca de acciones de Tile/Shortcut y nombres de archivo seguros.
3. **Capa Android (`MediaStoreSaver`, `ViewfinderGridOverlay`, `UniversalCameraController`, `RescuePreferences`, `AndroidManifest.xml`)**: Sesión transaccional MP4 en `Movies/S23Camera` (`IS_PENDING`), superposición de cuadrícula (`3x3` y `Cruz`), controlador unificado `Camera2` + `MediaRecorder` con `RECORD_AUDIO` opcional y degradable, persistencia de preferencias del visor y manifiesto `v2.0.0`.
4. **Integración `MainActivity` + Sync Build/CI (`v2.0.0`, `versionCode = 6`)**: Controles de visor universal en UI, temporizador con cuenta regresiva, gestión de permiso `RECORD_AUDIO` con fallback inmediato a video sin audio, flujos SAF `ACTION_CREATE_DOCUMENT`/`ACTION_OPEN_DOCUMENT` para perfiles `.json`, y sincronización de Gradle/scripts/GitHub Actions.

**Tech Stack:** Java 17, Android SDK 34 (`compileSdk = 34`, `minSdk = 30`, `targetSdk = 34`), APIs estándar del Android SDK sin dependencias externas, pruebas unitarias en Java puro sin JUnit (`scripts/test-local.ps1`), compilación local `aapt2`/`javac`/`d8`/`zipalign`/`apksigner` (`scripts/build-local.ps1`).

## Global Constraints
- **Platform:** Java 17, Android SDK `compileSdk = 34`, `minSdk = 30`, `targetSdk = 34`. Zero third-party dependencies (standard Android SDK APIs only; pure Java unit tests with no JUnit).
- **Pure-Java Test Boundary (`scripts/test-local.ps1`):** `javac` compiles `$PureSources` WITHOUT `android.jar` on the classpath. Every class included in `$PureSources` (`CameraConfig`, `DynamicUiBuilder`, `CameraViewerMath`, `VideoRecordingState`, `DiagnosticProfileCodec`, etc.) MUST use standard `java.*` packages only — NEVER `android.*` or `org.json.*`.
- **Privacy & Security:** 100% offline. NEVER add `android.permission.INTERNET`, broad storage permissions (`READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `MANAGE_EXTERNAL_STORAGE`), external libraries, or confidential business docs/keystores. Keep `RearCaptureService` and package `com.s23plus.camera` intact.
- **Version Sync (`v2.0.0`, `versionCode = 6`):** Must match across `CameraConfig.java`, `CameraConfigTest.java`, `AndroidManifest.xml`, `app/build.gradle.kts`, `scripts/build-local.ps1` (`dist/camera-rescue-v2.0.0.apk`), and `.github/workflows/release-apk.yml`.
- **TDD Rule:** For all pure Java logic (Tasks 1 & 2), write failing tests first, run `powershell -ExecutionPolicy Bypass -File .\scripts\test-local.ps1` to confirm RED, implement minimal code, re-run to confirm GREEN.
- **Verification Rule:** ALWAYS run and inspect final outputs of both `powershell -ExecutionPolicy Bypass -File .\scripts\test-local.ps1` and `powershell -ExecutionPolicy Bypass -File .\scripts\build-local.ps1` before closing `v2.0.0`.

## Review Focus
1. **Zoom strategy & boundary safety (`CameraViewerMath`):** `resolveZoomApplication` handles `NaN`/`Infinity`/`<= 0`, `null` capabilities, API `< 30` fallback to `SCALER_CROP_REGION`, and `<= 1.0f` ultra-wide zoom ratios without division by zero or invalid crop bounds.
2. **Variable aperture hardware mapping (`LENS_APERTURE`):** Only exposes `f/1.5` / `f/2.4` cycling when `ApertureCapabilities.variableApertureSupported` (`>= 2` distinct positive apertures), resets gracefully to `Auto` (`0.0f`) when switching to lenses without variable aperture, and applies `CaptureRequest.LENS_APERTURE` only when `> 0f`.
3. **MP4 `MediaRecorder` lifecycle & short-recording cleanup (`VideoRecordingState` + `MediaStoreSaver` + `UniversalCameraController`):** Strict `MediaRecorder` call order, `API 30` vs `API 31+` constructor guard, graceful fallback to video-only when `RECORD_AUDIO` is denied, and `abortPendingVideo` cleanup on `< 600ms` or `RuntimeException` in `stop()`.
4. **Strict `.json` profile validation (`DiagnosticProfileCodec`):** Rejects oversized inputs (`> 262,144` bytes), duplicate keys, trailing garbage, wrong types, unsupported `schemaVersion`, out-of-range sensor metrics, and `quickTileAction` values outside the allowlist (preventing intent-action injection on import).
5. **Backwards compatibility of `DynamicUiBuilder` & `MainActivity` lifecycle:** Existing `buildRearActionSpecs`, `getSelectableFrontSensors`, and `buildShortcutSpecs` contracts remain untouched (`DynamicUiBuilderTest` green); `onPause()` cancels countdown timers and stops active camera/video sessions cleanly; SAF export opens `OutputStream` with `"wt"` mode.
